# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub:
[Security > Report a vulnerability](https://github.com/OMAR9564/disclosly/security/advisories/new).
Include the affected component, the steps to reproduce and the impact you expect.

You will get an answer within 7 days. Once a fix ships, the advisory is published with credit to
the reporter, unless you ask to stay anonymous.

## Supported versions

Only the version currently deployed from `main` receives security fixes.

## Scope

In scope: the code in this repository, the API at `api.disclosly.com` and the web app at
`disclosly.com`. Please do not run load tests or automated scanners against production.
