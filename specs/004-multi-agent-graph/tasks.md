# Tasks: Phase 4 — Multi-Agent Research

**Input**: Design documents from `specs/004-multi-agent-graph/`

**Prerequisites**: [plan.md](./plan.md), [spec.md](./spec.md), [research.md](./research.md), [data-model.md](./data-model.md), [contracts/](./contracts/), [quickstart.md](./quickstart.md)

**Tests**: Required by the constitution (Principle II). Every task ships with the tests named in it; coverage stays ≥ 80% (backend and web separately). LLM-dependent tasks add eval cases replayed from cassettes; CI never calls a live provider and the eval gate never needs Docker.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: US1–US6 from [spec.md](./spec.md)

## Path Conventions

Backend packages at repo root (`api/`, `agent/`, `agent/graph/`, `llm/`, `tools/`, `sandbox/`, `evals/`), tests under `tests/unit/` and `tests/integration/`, web app under `web/src/` with tests under `web/tests/`.

## Engine rollout

`AGENT_ENGINE` defaults to `single` (the Phase 3 loop) until T061 switches it to `graph`, after US4 has given the graph a simple path. Before that, the graph runs only where a test or a local `.env` sets `AGENT_ENGINE=graph`.
