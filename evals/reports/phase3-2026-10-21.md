What changed (PR #61):

- Providers: all model ids checked live; `strong` now starts with `gemini-2.5-flash` (about 1 s;
  the 3.x flash models took 10 to 15 s and often returned 503), then `gemini-3.8-flash`,
  OpenRouter `nemotron-3-ultra-550b:free`, Groq `gpt-oss-120b`, GitHub Models.
- Router: 413 (Groq's 8,000 tokens per minute) skips without a cooldown; 404 is a config error.
- Gemini 3 rejected tool calls made by another provider after a fallback (missing
  `thought_signature`, HTTP 400, then a 1 h cooldown). The client now sends Google's documented
  placeholder.
- Validator: stated units must match the source scale (KAP "Sunum Para Birimi", SEC table
  headers, fact units); date day numbers are not figures; bare chunk ids are repaired.
- A search worker timeout is a tool error, not a failed run. A closed SSE tab is not a 500.

Still open:

- `GITHUB_MODELS_TOKEN` and the Cloudflare keys are not set on the server, so GitHub Models and
  Workers AI are skipped. Their model ids could not be checked without keys.
- Two `revenue` facts for ASELS 2025-Q2 (29.55 and 39.04 billion TRY) come from different
  reports; the later one is probably an inflation-adjusted restatement. Not fixed here.
- The system prompt has no current date, so "bu yıl" / "this year" questions guess the year.
  Adding the date changes every recorded cassette, so it needs a live re-recording.
- SC-001 needs the T046 sign-in test again after the deploy.
